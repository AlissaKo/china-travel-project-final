# China Travel — сайт и интерактивный квиз

Готовый проект на **React + Vite + Tailwind CSS**. Визуально ориентирован на предоставленный макет: тёмный сине-зелёный фон, красные акценты, карточки туров и блок подбора маршрута.

## Как открыть в VS Code

1. Распакуйте архив.
2. Откройте папку `china-travel-site` в VS Code.
3. Установите Node.js (рекомендуется актуальная LTS-версия).
4. Откройте Terminal в VS Code и выполните:

```bash
npm install
npm run dev
```

5. Откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173`).

Для проверки production-сборки: `npm run build`.

## Что уже сделано

- Главная страница по референсу.
- Страница «Туры» со всеми 10 направлениями и фильтрами.
- Страница «О нас и отзывы».
- Страница «Контакты» с демонстрационной формой.
- Карточки туров с подробным модальным окном.
- Интерактивный квиз из 5 вопросов, индикатор прогресса, подсчёт баллов, результат и показ обоих вариантов при ничьей.
- Адаптивная вёрстка для мобильных и десктопа.
- Tailwind CSS для стилей.

## Важно перед публикацией

Цены, телефон, email, отзывы и сроки в проекте — демонстрационные примеры, а не коммерческое предложение. Замените их на проверенные данные. Форма контактов сейчас показывает подтверждение на экране, но не отправляет данные на почту/CRM — для этого нужно подключить backend или сервис форм. Визуальные блоки туров сделаны CSS-иллюстрациями без внешних изображений, чтобы проект запускался без дополнительных файлов и API.

## 3. Алгоритм подсчёта и ничьи

1. Создать счёт для каждого из 10 туров, начальное значение — 0.
2. Для каждого ответа добавить перечисленные баллы соответствующим турам.
3. Сложить все начисления после пятого ответа; отрицательные баллы вычитаются.
4. Найти максимальный итоговый балл.
5. Если максимальный балл принадлежит одному туру — показать его как основной результат.
6. Если два или больше туров делят максимальный балл — показать их все как «близкие варианты», без скрытого приоритета.
7. В интерфейсе квиза нельзя получить результат до ответа на все 5 вопросов. Можно вернуться назад и изменить ответ.

**Почему все туры достижимы:** у каждого направления есть как минимум один вопрос/ответ с положительными баллами, а сочетание ответов может усилить соответствующее направление. Баллы видимы в коде и легко переносятся в Google Forms, Typeform или Tally.

## 4. Пример прохождения

Ответы:
1. «Древние дворцы, Великая стена и история» → classic +3, family +1, silk +1.
2. «Сбалансированный» → classic +1, yunnan +2, urban +1.
3. «С детьми» → family +4, classic +1, beach +1.
4. «Средний бюджет» → classic +1, urban +1, yunnan +1.
5. «Долгие переезды и сложная логистика» → family +2, urban +1, beach +1.

Итог:
- classic: 3 + 1 + 1 + 1 = **6**
- family: 1 + 4 + 2 = **7**
- yunnan: 2 + 1 = **3**
- urban: 1 + 1 + 1 = **3**
- silk: **1**
- beach: 1 + 1 = **2**
- остальные: **0**

Результат: **Семейный Китай** (7 баллов). Классика Китая — 6 баллов, близкий по смыслу вариант, но не ничья по баллам, поэтому по формальному правилу показывается только семейный тур.

## 5. Тексты результатов для туров

Тексты результатов расположены в массиве `tours` в `src/App.jsx`, поле `result`. Их можно редактировать напрямую. Для каждого направления есть 2–3 дружелюбных предложения и призыв к действию. Квиз показывает баллы победителя, а при точной ничьей выводит все туры с максимальным баллом.
